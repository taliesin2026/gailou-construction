# 盖楼吧！施工员

> 施工规范 · 沉浸式学习 —— 施工规范知识小游戏

从一块荒地开始，亲自动手完成 **11 道工序**：场地平整 → 测量放线 → 基坑支护 → 打桩 → 基础底板 → 地下结构 → 主体结构 → 砌体 → 门窗安装 → 机电 → 竣工验收备案。每完成一道工序，就要接受 **规范考点** 的考验。

## 特色

| | |
|---|---|
| 🏗️ **动手盖楼** | 锤击、砌砖、浇筑、试压——每道工序都有独立的施工操作台 |
| 📋 **33 道规范考点** | 真题数据，带条文出处 |
| 📖 **速查手册** | 9 大类 40+ 条关键数值 |
| 📕 **错题本** | 自动收集，随时重练 |
| 🏫 **支护桩专项课** | 围护桩施工期间的施工管理要点，8 节微课 |

## 运行

纯前端单文件应用，无构建、无依赖、无网络请求。双击 `index.html` 即可离线运行，或用任意静态服务器：

```bash
python3 -m http.server 8000   # 然后打开 http://127.0.0.1:8000
```
